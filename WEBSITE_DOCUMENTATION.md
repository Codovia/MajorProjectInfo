## 🔧 Customization Guide

### To Edit Content:
1. **Team Members:** Edit `src/pages/TeamPage.jsx` - Modify `teamMembers` array
2. **Guide Info:** Edit `src/pages/TeamPage.jsx` - Modify `guide` object
3. **College/College:** Edit `src/components/Footer.jsx` - Update footer info
4. **Colors:** Edit `tailwind.config.js` - Modify color scheme
5. **Animations:** Edit `src/index.css` - Adjust keyframes

### To Add Sections:
1. Create new component in `src/components/`
2. Import in `src/pages/HomePage.jsx`
3. Add to the page layout
